# zenithnms-docs

이 저장소는 **자동 생성된 문서 사이트**입니다. 직접 편집하지 마세요.

- **문서 사이트**: https://sinokorofficial.github.io/zenithnms-docs/
- **소스 코드 및 문서 원본**: [SinokorOfficial/zenithnms](https://github.com/SinokorOfficial/zenithnms) (private) — `docs/` 폴더, `mkdocs.yml`
- **갱신 방식**: `zenithnms`의 `master` 브랜치에 `docs/**` 변경이 push되면 GitHub Actions(`.github/workflows/docs.yml`)가 MkDocs로 빌드해 이 저장소의 `gh-pages` 브랜치로 자동 push합니다.

문서를 수정하려면 이 저장소가 아니라 `zenithnms`의 `docs/` 폴더를 고치세요.
