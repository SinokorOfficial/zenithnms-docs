    SNMP Poller — Data Flow¶

    Scheduler (60s interval)
        │
        ▼
PollerEngine.run_cycle()
        │
        ├── SELECT enabled devices FROM DB
        │
        ├── asyncio.gather(*[_poll_one(device) for device])
        │         │
        │         ├── Semaphore(POLLER_WORKERS=20) — max 20 concurrent
        │         │
        │         └── SNMPWorker.collect(device)
        │               ├── SNMP GET sysDescr/sysName/sysOID
        │               ├── CPU/Mem: sysDescr/sysObjectID로 벤더 자동 감지 →
        │               │     벤더 전용 OID 우선 시도, 실패 시 UCD-SNMP →
        │               │     HR-MIB → Cisco/TP-Link/H3C/... 순차 폴백
        │               │     (전체 전략 순서는 docs/manual.md 14장 참고)
        │               └── SNMP BulkWalk IF-MIB + IF-MIB HC
        │                     ├── ifDescr, ifSpeed, ifOperStatus
        │                     ├── ifHCInOctets, ifHCOutOctets (64-bit)
        │                     └── counter_delta() → bps rate calculation
        │
        ├── INSERT INTO metrics_raw (batch)
        ├── UPDATE devices.status
        └── AlertEngine.check_latest(results)
              ├── Compare value vs thresholds
              ├── CREATE AlertEvent if exceeded
              └── RESOLVE existing alert if recovered

    Topology Discovery Algorithm¶

    Input: CIDR (e.g. 192.168.0.0/24), community string

Phase 1 — SNMP Probe (parallel, Semaphore(50))
  ┌─────────────────────────────────────────────────┐
  │ for each host in CIDR:                          │
  │   try SNMP GET sysName + sysDescr + sysObjectID │
  │   → alive_nodes[]                               │
  └─────────────────────────────────────────────────┘

Phase 2 — Neighbor Discovery (parallel)
  ┌──────────────────────────────────────────────────────────┐
  │ for each alive node:                                     │
  │   try LLDP-MIB Walk (lldpRemTable)                       │
  │     → lldpRemSysName[suffix] → neighbor name             │
  │     → lldpRemMgmtAddr[suffix] → neighbor IP              │
  │     → lldpRemPortId[suffix] → remote port                │
  │     → lldpLocPortId[localIdx] → local port               │
  │   if LLDP empty → try CDP-MIB Walk (Cisco)               │
  │     → cdpCacheDeviceId, cdpCacheAddress                  │
  └──────────────────────────────────────────────────────────┘

Phase 3 — Graph Construction
  nodes = {ip: NodeInfo}  ← all probed + discovered IPs
  edges = [EdgeInfo(src_ip, dst_ip, src_port, dst_port, link_type)]

Phase 4 — Edge Deduplication
  key = (min(src, dst), max(src, dst)) → remove A→B when B→A exists

Phase 5 — Force-directed Layout (Fruchterman-Reingold)
  F_repel = k² / d    (all node pairs)
  F_attract = d² / k  (connected pairs)
  cooling: temperature t *= 0.95 per iteration
  → x_pos, y_pos for each node

Phase 6 — DB Persistence
  TopologySnapshot (is_active=True) + TopologyNode[] + TopologyEdge[]

    Scalability Notes¶

    Component Current Scale-out
    Poller Single process asyncio Multiple Celery workers + Redis queue
    Counter cache In-process dict Redis hash (shared across workers)
    Database PostgreSQL table partitioning TimescaleDB hypertable + compression
    WebSocket Not implemented FastAPI WebSocket + Redis Pub/Sub
    Frontend Vite SPA CDN distribution
